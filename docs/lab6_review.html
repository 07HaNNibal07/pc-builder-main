[ЛР4-20] Интеграция LLM-консультанта через OpenAI API и настройка контекста каталога

Ответственный: Бабаев Ильгар · Статус: In Progress

Период: 2027-01-01 — 2027-01-14 · недели 10–11 · Оценка: 14 часов

Зависимости: №7 FS; №10 FS

Интеграция LLM-консультанта через OpenAI API по текущему запросу пользователя. Исходное название ЛР4 с Ollama сохранено в поле original_title; номер, часы, период и зависимости не изменены.

Подтверждено аудитом

api/ai/llm.py поддерживает OpenAI и Ollama; router.py и agent.py реализуют чат и инструменты. Тесты используют FakeModel; реальный вызов OpenAI в ЛР6 не выполнялся.

Критерии приёмки

  • ☐ Использовать существующий ChatOpenAI и инструменты recommend_pc, get_build_details, find_component_options, suggest_upgrade.
  • ☐ Проверить ответ на запрос по бюджету, получение цен/FPS из инструмента и уточнение с тем же session_id.
  • ☐ Убедиться, что данные разных сессий не смешиваются; учитывать, что MemorySaver теряет контекст при перезапуске.
  • ☐ Проверить валидацию, отсутствие настройки, тайм-аут и недоступность провайдера; ключи и тексты приватных диалогов не прикладывать.
  • ☐ Приложить обезличенный протокол реального OpenAI-запроса; наличие кода и FakeModel не является такой проверкой.
