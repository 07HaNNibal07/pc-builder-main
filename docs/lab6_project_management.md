## Учебные допущения

- Начало проекта условно принято 30.10.2026, окончание — 04.02.2027. Это плановый календарь демонстрации, а не утверждение об историческом старте разработки.
- Неделя N: начало + 7×(N−1) дней; окончание недели N: начало + 7×N−1 дней. Праздники не исключаются; часы — трудоёмкость, а не длительность календарного периода.
- ФИО взяты из ЛР4 и запроса. GitHub-логины не выдуманы: ответственные указаны текстом в карточках и метках Owner.
- Статусы основаны на локальных артефактах. In Progress означает наличие частичного результата с незавершённой проверкой, Todo — отсутствие подтверждения реализации в доступных материалах. Ни одна задача не переведена в Done без приёмки.
- Номера ЛР4 и GitHub Issues — разные идентификаторы; поле issue_url содержит проверенную ссылку на реальную Issue. Реальные ссылки GitHub заполнены после создания и проверки Issues.

## Процесс управления

Team Lead уточняет критерии, проверяет зависимости и принимает результат. Ответственный ведёт карточку и прикладывает доказательства. QA/DevOps регистрирует результаты проверок и дефекты. Команда еженедельно сверяет даты, трудоёмкость и блокировки; исходная оценка хранится отдельно от фактически затраченного времени. Из Todo в In Progress задача переходит при начале работ; из In Progress в Done — после выполнения критериев и проверки. Возврат на доработку отражается статусом и причиной в карточке. Завершение задачи не определяется наличием одного файла или общей датой проекта.
